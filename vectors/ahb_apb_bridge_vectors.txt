// format: HRESETn HSEL (bin) HADDR(hex) HTRANS(bin) HWRITE(bin) HWDATA(hex) hready_other(bin)
//         PREADY_UART PREADY_GPIO PREADY_DMAC PREADY_VGA (bin)
//         expected: HRDATA(hex) HREADYOUT(bin) PADDR(hex) PWRITE(bin) PWDATA(hex) PENABLE PSEL_UART PSEL_GPIO PSEL_DMAC PSEL_VGA (bin)
//         wait_type
// The bus HREADY is HREADYOUT AND hready_other (hready_other = 0 models another slave's data phase).
// PRDATA_UART/GPIO/DMAC/VGA are fixed at 0000AAAA / 0000BBBB / 0000CCCC / 0000DDDD.
