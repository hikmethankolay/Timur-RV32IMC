// dmac_apb_regs test vectors, one operation per line
// format: op(dec) a(hex) b(hex) c(hex)
//   op 0  read          a = PADDR, b = expected PRDATA
//   op 1  write         a = PADDR, b = PWDATA
//   op 2  engine busy   a = dmac_busy level
//   op 3  engine done   one-cycle dmac_done pulse
//   op 4  start pulses  a = number of one-cycle dmac_start pulses since the last check
//   op 5  outputs       a = dmac_src, b = dmac_dst, c = dmac_len
//   op 6  irq           a = expected irq
//   op 7  CTRL write with a dmac_done pulse in the same (ACCESS) cycle: a = PADDR, b = PWDATA
// Registers: 0x00 SRC, 0x04 DST, 0x08 LEN, 0x0C CTRL (bit 0 start, bit 1 irq_enable),
// 0x10 STATUS (bit 0 busy, bit 1 done). PREADY = 1 and PSLVERR = 0 checked in every ACCESS.
//
